# ci-cd-final-project

## Project Name
ci-cd-final-project

## Project Description
This project demonstrates CI/CD concepts using GitHub Actions, Tekton, and OpenShift.

## Features
- Continuous Integration using GitHub Actions
- Code linting using Flake8
- Unit testing using Nose
- Continuous Delivery using Tekton
- Container image build using Buildah
- Deployment to OpenShift
